📖 How to Use

Get started with MUNIM

A complete step-by-step guide — from first launch to your first set of books.

First Day
Setting up MUNIM
Follow these steps in order on the day you start using MUNIM.
1
Download and run MUNIM.exe
Keep the .exe in a permanent folder (e.g. E:\Munim\). Double-click to open. If Windows SmartScreen appears, click More info → Run anyway. This is normal for new software and not a virus warning about MUNIM specifically.
💡 Accept the desktop shortcut offer — MUNIM will keep it updated if you move the .exe
2
Activate your copy
On first run, an activation screen appears. Enter the username, password and licence key provided when you purchased. The key is validated offline — no internet needed. Done in 30 seconds.
3
Change the default password
On first login, MUNIM asks you to set a new password (minimum 8 characters). Choose something you will remember — there is no "forgot password" button. If you forget it, WhatsApp us and we will reset it.
4
Set up Company Details
Go to Utilities → Company Details. Enter your business name, GSTIN, address and state. This information appears on invoices and reports. If you are not GST registered, uncheck the GST Registered box — tax fields will be hidden.
5
Add your customers and suppliers
Go to Masters → Party Master. Add each customer and supplier with their GSTIN and opening balance (what they owe you / you owe them on the starting date). You can also add parties later directly from the invoice screen using the + New button.
💡 Set credit days for each party to use due-date ageing in Outstanding reports
6
Enter opening balances
If you are starting mid-year with existing balances, enter a Journal dated on your opening day: Dr Cash/Bank, Cr Capital for cash in hand. For other account opening balances, go to Masters → Ledger Accounts and double-click any account to set its opening balance.
Daily Use
Recording transactions every day
A
Recording a sale to a customer
Go to Transactions → Sales Invoice. Select the customer, enter items with quantity, rate and GST%. MUNIM calculates CGST/SGST or IGST automatically. If the customer pays now, enter the amount in Received now. Save — the entry posts to Sales Register, Ledger, and Trial Balance automatically.
💡 For walk-in customers: select Cash as the party and type the customer name in "Customer name on bill"
B
Counter sales for the day (retail/B2C)
If you have many small cash sales without individual invoices, use Transactions → Daily Sales Summary. Enter the total amount per GST rate for the day. Tick "Amounts include GST" if your prices are tax-inclusive. One entry covers the whole day.
C
Recording a purchase from a supplier
Go to Transactions → Purchase Bill. Select the supplier, enter items with GST%. Input CGST/SGST/IGST is posted automatically. If you pay now, enter the amount in Paid now.
D
Receiving payment from a customer later
Go to Transactions → Receipt / Payment. Select Receipt from customer, pick the party, enter the amount. MUNIM settles the oldest unpaid bill first. Any excess stays as advance on account. You can see all settled bills in the confirmation message.
E
Recording an expense (rent, salary, electricity)
First create the expense account if it does not exist: Masters → Ledger Accounts → add "Electricity" under Direct/Indirect Expenses. Then go to Transactions → Voucher Entry, type Payment, and enter: Dr Electricity, Cr Cash.
F
Fixing a mistake
Open Reports → Day Book, find the entry, double-click it. A window opens showing full details. Click Edit to change it or Delete to remove it. Every change is logged in Utilities → Audit Log.
💡 Vouchers that settle bills cannot be edited — delete and re-enter instead

Good to Know
Tips for clean books
💾 Back up weekly
Go to Utilities → Backup Data. Save to a USB drive or cloud folder — not only on the same PC. The Gateway shows days since last backup in red if overdue.
📊 Check Trial Balance monthly
A balanced trial balance (Dr = Cr) means your entries are correct. Run it at the end of each month before filing GST returns.
🧾 GST invoices vs Daily Summary
Use Sales Invoice for every sale to a GST-registered business. Use Daily Sales Summary only for small B2C counter sales where the buyer does not need a tax invoice. Confirm with your CA.
📅 Financial year
MUNIM uses Indian FY (April–March). Reports have a FY picker — you can view any past year at any time. Prior year balances carry forward automatically.
🔑 Password safety
Change the default password immediately after first login. Keep it somewhere safe. If you forget it, WhatsApp us — we can reset it remotely.
📈 Opening and closing stock
Until the stock module is built, enter opening and closing stock manually on the Trading & P&L screen. Opening follows last year's closing automatically unless you change it.
