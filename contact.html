Self Help
Common issues and fixes

Check here first — most issues have a simple fix.

Windows says MUNIM is unsafe or blocked it
This is a Windows SmartScreen warning for new software. Click "More info" then "Run anyway". MUNIM is completely safe — no virus, no malware.
See installation guide →
MUNIM won't open after double-clicking
Right-click MUNIM.exe → "Run as administrator". If it still doesn't open, your antivirus may be blocking it — add MUNIM.exe as an exception.
I forgot my MUNIM password
Password recovery is not available to protect your data. If you are the computer's admin user, contact us on WhatsApp — we can guide you through a manual reset.
How do I move MUNIM to a new computer?
Copy the entire C:\MUNIM\ folder to a USB drive. Install MUNIM.exe on the new computer, then paste the MUNIM folder back to C:\. All your data will be there.
See backup guide →
Trial Balance is not balancing
This usually means an opening balance entry is missing or entered on the wrong side. Check your opening balances in Settings → Opening Balances and ensure Dr and Cr totals match.
Invoice is not printing correctly
Go to Settings → Print Settings and check that the correct printer and paper size (A4 or Thermal) is selected. Try "Print Preview" first before sending to printer.
How do I take a backup of my data?
Go to Settings → Backup & Restore → click "Take Backup". Or manually copy C:\MUNIM\ to any external drive or USB. Do this regularly — especially before updating MUNIM.
MUNIM is running slowly
Close other heavy applications while using MUNIM. If your data is very large (2+ years of entries), go to Settings → Database → Compact Database to improve speed.
Bug Report
How to report a bug properly

A good bug report helps us fix it faster.

When reporting a bug, please include:
The more information you give us, the faster we can fix it. Send this over WhatsApp or email.
  • Your Windows version (Windows 10 or 11, 32-bit or 64-bit)
  • MUNIM version number (shown at bottom of the MUNIM window)
  • What you were doing when the bug happened
  • Exact steps to reproduce the bug
  • A screenshot of the error message if any
  • Whether this happens every time or only sometimes
